# ADR 0001: Deliver Phase A+B first

## Status

Accepted

## Context

The approved architecture scope spans foundational repo restructuring, CI, data lineage model evolution, underwriting kernel, and authorization rework.

## Decision

Deliver Phase A (engineering foundation) and Phase B (quality gates) as the first reviewable PR, preserving live behavior and safeguards.

## Consequences

- The repository gains architectural boundaries and safety gates first.
- Phase C–E implementation can proceed in smaller, safer follow-up PRs.
